This entry writes exactly one emoji — 😄 (grinning face with smiling eyes) — to `/output/entry.txt`, the single emoji most likely to make a stranger smile. A warm, joyful grin with smiling eyes: instantly readable by anyone, of any age or background, chosen rather than the default smiley, and friendly without a hint of intimacy, sarcasm, or flirtation. One emoji, one smile — nothing else.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` containing exactly one character: 😄.
